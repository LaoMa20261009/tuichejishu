# 螃蟹称重与绳色识别

Windows WinForms 上位机。使用 Visual Studio 2012（版本 11.0）打开 `CrabWeighing.sln`，选择 `Debug | x86` 或 `Release | x86`。工程使用 C# 5 和 .NET Framework 4.5，无 NuGet 依赖。

## 卖家提供的三个压缩包

| 压缩包 | 实际内容 | 在本项目中的用途 |
| --- | --- | --- |
| `PBX系列OS2X接口开发包.rar` | V1.009 的 DLL 及示例程序、C# 与 Delphi 示例源码、V1.032 的串口通信协议文档 | 用于核对秤的通信格式。协议文档也可用于后续从串口直接读取数据。 |
| `顶尖通训秤 CH341SER.rar` | `CH341SER.EXE` 驱动安装程序 | 秤或转接线使用 CH340/CH341 且 Windows 还未识别出 COM 口时使用。可先在设备管理器查看。 |
| `最新OS2动态库--dingjian.rar` | OS2 SDK V1.017、32 位 `SensorDll.dll`、C# 示例、接口说明及厂商工具，另附一份相同的 PBX 开发包 | **本程序读取称重使用这份 SDK。** 取 `最新OS2动态库\OS2_SDK_V1.017\SensorDll.dll` 顶层 DLL。 |

源码构建时，可将上述 DLL 放在工程的 `vendor\SensorDll.dll`，构建时会复制到程序目录。也可以在运行前把 DLL 直接放到 `CrabWeighing.exe` 同一目录。SDK 与程序均需使用 x86，即使 Windows 是 64 位。

## 1280×800 面板

主窗口沿用 Stitch 的 1280×800 比例，目标尺寸为 2560×1600。屏幕较小时按比例缩小以容纳内容。拖动顶部标题栏可移动窗口，保存、连接或播放时窗口尺寸固定。右上角保留最小化和关闭操作。

## 按工单装箱

1. 在左侧选择「本地视频」并连接，推荐 H.264 MP4。Windows 自带的解码器负责本地视频播放。现场支持 RTSP、HTTP 和 DirectShow 相机，使用 FFmpeg 解码。可通过「选解码器」指定 `ffmpeg.exe`。工业相机需提供上述任一视频接口。秤通过设备管理器里的实际 COM 口和厂商 SDK 连接。
2. 通过右侧「手动扫码」录入箱码。键盘式扫码枪可以把码直接输入这个窗口。设定红、绿、蓝、白四种规格的目标只数并启用工单。已有箱码可以读取原目标和取放记录。
3. 固定相机，在画面内拖动框选装箱区域。新工单从空箱开始，有皮重时等秤稳定再点「去皮」。去皮只影响上位机的净重，重新连接秤后需重新确认。
4. 每次操作只放入或取出同一种绳色。程序对比操作前后稳定的分色数量和净重，同时确认重量变化方向。确认后新增取放记录，并更新已装、剩余和装箱进度。多个颜色同时变化时会留在待确认状态，可恢复上一稳定状态后分开操作。恢复已有工单时，先放回原箱并核对数量和净重。
5. 「绳色规格配置」支持品名及单只重量范围。取放记录的重量变化来自实秤读数之差。多只同色同时操作时，以变化量除以只数所得均重核对范围，超范围记录标记 `!`。
6. 双击取放记录的缩略图可查看原图。每条记录保存操作前、操作后和一个目标裁剪图。文件按箱码保存在 `%LOCALAPPDATA%\CrabWeighing\packing-live` 下，模拟记录使用独立的 `packing-demo` 目录。界面显示当前工单最近 200 条。

### 模拟试用

在视频区域选择「演示画面」并连接。勾选「模拟秤」并连接，再创建模拟工单。自动放蟹会从空箱开始依次放入、取出。也可关闭「自动放蟹」手动改数量。切换到实秤时需选择实测工单。

### 验证范围

已编译为兼容 Visual Studio 2012 的 .NET Framework 4.5 x86 Windows 程序。视觉算法沿用系绳区域检测，未使用设计稿中示例标注的 YOLOv8。遮挡、缠绕及反光需要用现场视频校验。Windows 上的相机、秤、扫码枪和播放效果需要实机联调。
