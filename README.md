# 螃蟹称重与绳色识别

Windows WinForms 上位机。使用 Visual Studio 2012（版本 11.0）打开 `CrabWeighing.sln`，选择 `Debug | x86` 或 `Release | x86`。工程使用 C# 5 和 .NET Framework 4.5，无 NuGet 依赖。

## 卖家提供的三个压缩包

| 压缩包 | 实际内容 | 在本项目中的用途 |
| --- | --- | --- |
| `PBX系列OS2X接口开发包.rar` | V1.009 的 DLL 及示例程序、C# 与 Delphi 示例源码、V1.032 的串口通信协议文档 | 用于核对秤的通信格式。协议文档也可用于后续从串口直接读取数据。 |
| `顶尖通训秤 CH341SER.rar` | `CH341SER.EXE` 驱动安装程序 | 秤或转接线使用 CH340/CH341 且 Windows 还未识别出 COM 口时使用。可先在设备管理器查看。 |
| `最新OS2动态库--dingjian.rar` | OS2 SDK V1.017、32 位 `SensorDll.dll`、C# 示例、接口说明及厂商工具，另附一份相同的 PBX 开发包 | **本程序读取称重使用这份 SDK。** 取 `最新OS2动态库\OS2_SDK_V1.017\SensorDll.dll` 顶层 DLL。 |

源码构建时，可将上述 DLL 放在工程的 `vendor\SensorDll.dll`，构建时会复制到程序目录。也可以在运行前把 DLL 直接放到 `CrabWeighing.exe` 同一目录。SDK 与程序均需使用 x86，即使 Windows 是 64 位。

## 先运行演示

1. 视频类型选「演示画面」，点击「连接视频」。
2. 勾选「模拟秤」，点击「连接秤」，再点「放上演示筐」。
3. 界面会显示白色、红色和 2.350 kg。同一筐通过判定后生成一条「演示」记录。移筐并等空秤状态确认后，即可测试下一筐。

演示模式无需安装驱动、厂商 DLL 或 FFmpeg。

## 导入本地视频

视频类型选「本地视频」，点击「选择视频」，从电脑选中 MP4、MOV、AVI、MKV 等视频，然后点击「连接视频」。请将 Windows 版 FFmpeg 加入 PATH，或在界面的 FFmpeg 栏填写 `ffmpeg.exe` 的完整路径。视频在电脑上循环播放，可直接查看绳色，也可搭配模拟秤生成演示记录。

## 连接现场设备

1. **相机。** 准备 Windows 版 FFmpeg。在界面输入 `ffmpeg.exe` 的完整路径，或者把 FFmpeg 加入 PATH。网络相机选择「网络视频」，填写 RTSP 或 HTTP 视频流地址。USB 相机选择「USB 摄像头」，填写 DirectShow 设备名。可用下面的命令列出设备。
   ```powershell
   ffmpeg -list_devices true -f dshow -i dummy
   ```
2. **秤。** 在设备管理器确认 COM 口并在界面选中或输入，例如 `COM3`。COM 通信按卖家资料使用 9600 波特率。使用秤的 USB 打印类接口时可试「USB 自动发现」。SDK 的自动打开会优先发现支持的 USB 打印类秤。同时接有多台秤时，联调时只接目标秤确认读数。通信模式按秤上实际设定选「主动上报」「被动查询」或「数字 OP 盒」。界面的选择用于读取对应协议，秤端的协议由设备侧配置。
3. **识别区域。** 固定相机和照明。在预览中拖出筐内区域，尽量排除筐边、背景、标签和强反光。识别以颜色和细条形状为依据。覆盖率调低可检出占画面更少的绳子，调高可减少孤立误判。支持白、红、橙、黄、绿、蓝、紫。
4. **自动记录。** 先在空秤时确认皮重已按现场流程扣除。按秤当前单位设置空秤上限和稳定容差。例如秤显示 kg 时，空秤上限 `0.020` 表示 20 g。开启「自动记录」。有效净重需持续稳定至少约 1 秒，且至少有两次称重读数和三帧一致绳色。同一筐完成后，空秤稳定约 0.6 秒才接收下一筐。
5. **历史。** 下半区显示时间、绳色、净重、单位和来源，重启会加载本地文件。点击「打开记录目录」可找到 `%LOCALAPPDATA%\CrabWeighing\measurements.tsv`，可在 Excel 中按 UTF-8、制表符分隔导入。

软件以一次上秤为一个批次，多种绳色与整筐净重保存在同一条记录。要得到单只螃蟹的重量，每次单独上秤；要统计某颜色的整批重量，可按颜色分筐称。绳子遮挡、重叠、反光或背景细条颜色相近会影响识别，现场应使用代表性画面校准识别区和阈值。

工程已使用 .NET Framework 4.5 参考程序集和 C# 5 编译为 x86 Windows 程序。已验证 FFmpeg 的 HTTP MJPEG 实时流和本地视频解码、合成样片的双色识别、稳定及卸筐判断和本地历史读写。仍需在实际 Windows 工作站上验证 WinForms 界面、秤的 SDK 通信、相机接入和现场识别效果。
