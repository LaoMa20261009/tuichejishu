# 螃蟹称重与绳色识别

Windows WinForms 上位机。使用 Visual Studio 2012（版本 11.0）打开 `CrabWeighing.sln`，选择 `Debug | x86` 或 `Release | x86`。工程使用 C# 5 和 .NET Framework 4.5，无 NuGet 依赖。

## 卖家提供的三个压缩包

| 压缩包 | 实际内容 | 在本项目中的用途 |
| --- | --- | --- |
| `PBX系列OS2X接口开发包.rar` | V1.009 的 DLL 及示例程序、C# 与 Delphi 示例源码、V1.032 的串口通信协议文档 | 用于核对秤的通信格式。协议文档也可用于后续从串口直接读取数据。 |
| `顶尖通训秤 CH341SER.rar` | `CH341SER.EXE` 驱动安装程序 | 秤或转接线使用 CH340/CH341 且 Windows 还未识别出 COM 口时使用。可先在设备管理器查看。 |
| `最新OS2动态库--dingjian.rar` | OS2 SDK V1.017、32 位 `SensorDll.dll`、C# 示例、接口说明及厂商工具，另附一份相同的 PBX 开发包 | **本程序读取称重使用这份 SDK。** 取 `最新OS2动态库\OS2_SDK_V1.017\SensorDll.dll` 顶层 DLL。 |

源码构建时，可将上述 DLL 放在工程的 `vendor\SensorDll.dll`，构建时会复制到程序目录。也可以在运行前把 DLL 直接放到 `CrabWeighing.exe` 同一目录。SDK 与程序均需使用 x86，即使 Windows 是 64 位。

## 导入视频并记录

1. 在「实时视频」选择「本地视频」，点击「选择视频」和「连接视频」。软件使用 Windows 内置媒体解码器逐帧播放，无需 FFmpeg。推荐 H.264 编码的 MP4，其他格式取决于当前 Windows 安装的解码器。
2. 在右侧勾选「模拟秤」，点击「连接秤」。「自动放蟹」会循环模拟空筐、1 只、2 只、4 只和 3 只，重量先变化再稳定。也可以关闭自动放蟹，手动修改「筐内只数」。需要实测时，连接实体秤并按现场操作放蟹。
3. 「参考重量」默认红色 200.0 克、绿色 250.0 克、蓝色 300.0 克，可以在界面修改并保存。白绳也可以计数，白绳参考重量初始为 0，代表待配置。
4. 程序约每 0.3 秒取样框选区域，寻找红、绿、蓝、白绳形成的独立目标，在视频上画出识别框。连续两次取样的分色数量一致时，右侧更新数量，即使没有连接秤。识别基于一只螃蟹一组可见系绳的前提。相邻绳子连在一起、同一只螃蟹有多处相互分离的绳圈、遮挡或反光都可能造成误计，可在视频上核对识别框。
5. 开启「自动记录」后，稳定分色数量和秤重一起保存到「识别历史记录」。每种绳色单独一条，同次记录共享时间。单色使用实测净重，混色按每色只数和参考重量分配，来源注明「重量估算」。混装白绳时需配置白绳参考重量。可通过「核对数量」保存人工核对的结果。
6. 视频播完可点「重播视频」。没有视频文件时，可选「演示画面」搭配模拟秤。

## 连接现场设备

1. **相机。** FFmpeg 是用于读取 RTSP、HTTP 或 USB 相机的解码工具。仅网络视频或 USB 相机模式会显示「相机解码器」。将 Windows 版 `ffmpeg.exe` 放在程序目录、加入 PATH，或填写完整路径。网络相机选择「网络视频」，填写 RTSP 或 HTTP 视频流地址。USB 相机选择「USB 摄像头」，填写 DirectShow 设备名。可用下面的命令列出设备。
   ```powershell
   ffmpeg -list_devices true -f dshow -i dummy
   ```
2. **秤。** 在设备管理器确认 COM 口并在界面选中或输入，例如 `COM3`。COM 通信按卖家资料使用 9600 波特率。使用秤的 USB 打印类接口时可试「USB 自动发现」。SDK 的自动打开会优先发现支持的 USB 打印类秤。同时接有多台秤时，联调时只接目标秤确认读数。通信模式按秤上实际设定选「主动上报」「被动查询」或「数字 OP 盒」。界面的选择用于读取对应协议，秤端的协议由设备侧配置。
3. **识别区域。** 固定相机和照明。在预览中拖出筐内区域，尽量排除筐边、背景、标签和强反光。识别以颜色和细条形状为依据。覆盖率调低可检出占画面更少的绳子，调高可减少孤立误判。支持白、红、橙、黄、绿、蓝、紫。
4. **称重。** 实时净重、空秤上限和稳定容差统一使用克。实时净重显示一位小数。正式记录前先按现场流程扣除筐的皮重。视频分色数量及稳定净重的变化会触发重新判断。
5. **历史。** 新记录保存在 `%LOCALAPPDATA%\CrabWeighing\measurements-grams.tsv`，包含时间、单一绳色、净重（克）、数量和来源，可按 UTF-8 制表符导入 Excel。旧的单色记录可自动读取并转换为克，旧混色记录仍可在原 `measurements.tsv` 查看。

## 验证范围

工程已使用 .NET Framework 4.5 参考程序集和 C# 5 编译为 x86 Windows 程序。已用合成画面验证空筐、同色多目标、白绳、混色和识别区域，已验证同重量下的分色数量变化会触发新的记录。Windows 本地视频解码、1280×800 界面和现场视频识别效果需在 Windows 一体机验证。
