# 螃蟹称重与绳色识别

Windows WinForms 上位机。使用 Visual Studio 2012（版本 11.0）打开 `CrabWeighing.sln`，选择 `Debug | x86` 或 `Release | x86`。工程使用 C# 5 和 .NET Framework 4.5，无 NuGet 依赖。

## 卖家提供的三个压缩包

| 压缩包 | 实际内容 | 在本项目中的用途 |
| --- | --- | --- |
| `PBX系列OS2X接口开发包.rar` | V1.009 的 DLL 及示例程序、C# 与 Delphi 示例源码、V1.032 的串口通信协议文档 | 用于核对秤的通信格式。协议文档也可用于后续从串口直接读取数据。 |
| `顶尖通训秤 CH341SER.rar` | `CH341SER.EXE` 驱动安装程序 | 秤或转接线使用 CH340/CH341 且 Windows 还未识别出 COM 口时使用。可先在设备管理器查看。 |
| `最新OS2动态库--dingjian.rar` | OS2 SDK V1.017、32 位 `SensorDll.dll`、C# 示例、接口说明及厂商工具，另附一份相同的 PBX 开发包 | **本程序读取称重使用这份 SDK。** 取 `最新OS2动态库\OS2_SDK_V1.017\SensorDll.dll` 顶层 DLL。 |

源码构建时，可将上述 DLL 放在工程的 `vendor\SensorDll.dll`，构建时会复制到程序目录。也可以在运行前把 DLL 直接放到 `CrabWeighing.exe` 同一目录。SDK 与程序均需使用 x86，即使 Windows 是 64 位。

## 两步装箱界面

主窗口采用科技蓝配色，带固定窗口边框。设计基准为 1280×800，可按屏幕比例放大至 2560×1600。拖动顶部标题栏即可移动窗口。

### 1. 标签文字 OCR

- 在「系统配置」选择实际电子秤接口及视频源，连接设备。支持本地视频、演示画面、RTSP/HTTP 和 DirectShow。网络与 USB 相机解码需要 FFmpeg。真实电子秤读取仍使用卖家提供的 SDK。
- 点击「实时视频」连接视频后，系统会自动抓拍并识别标签，也可点按「立即抓拍」。切换到「上传图片文字识别」可选择或拖入标签照片。系统本地执行整图和多分区文字识别，显示原始文字和可确认的位置框。
- 原始文字可复制。规格列表可点按打开编辑弹窗，支持加入红、绿、蓝、白、黄绳规格，每种绳色在一个工单中对应一种规格。可修改名称、单只克重范围、绳色和计划只数，或删除与重置。
- 图片条码支持 Code 128、EAN-13 和二维码。单码可带入箱码，多码需选择。添加规格填写与识别列表一致的五项字段，记录保存在工单的 `manual-audit.tsv`。没有可用的照片码时，确认可以生成本地箱码。
- OCR 优先使用 Windows 10/11 的简体中文文字识别功能，可以使用已安装的 Tesseract 及 `chi_sim` 数据作为补充。识别不足时可在同页手动补录。照片不会上传到外部服务。
- 确认规格后选择「开始装箱」进入第二页。相机、秤在线状态来自程序实际连接。附件中的 PLC 状态是示例，尚未接入现场 PLC 寄存器。

### 2. 装箱核对

- 在「系统配置」勾选「使用模拟秤」，点按「启动模拟秤」。没有已连接的视频时会启动演示画面。设置页和装箱页可以模拟放入或取出 1–4 只，并查看实时克重。装箱页按选中的规格模拟取放，净重稳定后写入该规格的模拟流水，原视频源可继续播放。开启「自动演示」后，演示箱会以空箱为起点，按工单规格分批投放，目标未达成时会演示取出。每批变动会等重量和画面稳定后入账。模拟工单单独保存。

- 新工单以空箱画面和稳定空箱净重建立基线。空箱放上秤台后可去皮。白色泡沫箱边沿应入镜。画面有多个箱子时，可在实时预览画面拖动框选秤上的箱子。
- 每次放入或取出同一种绳色。系统按稳定画面和电子秤的实测重量变化写入流水。点击左侧规格卡可查看该规格的序号、时间、取放、变动只数、重量变动和分规格累计重量。双击流水查看取放快照。
- 净重稳定但画面暂未确认的记录进入「待确认记录」。同一次取放随后能唯一识别时会补全原记录。也可双击待确认流水，查看快照后填写实际绳色、数量和操作员工号。完成装箱会检查所有规格的精确目标数量和待确认状态。保存成功后自动回到识别页，清空上一箱的识别信息，等待识别下一箱。
- 工单、记录和缩略图保存在 `%LOCALAPPDATA%\CrabWeighing\packing-live`，模拟秤使用独立的 `packing-demo`。完成状态保存在 `completed.txt`，完成的工单不再接受新的取放。返回第一步将暂停记录。

条码解码使用 ZXing.Net 0.16.9，二进制和 Apache 2.0 许可证附在工程或运行包中。
